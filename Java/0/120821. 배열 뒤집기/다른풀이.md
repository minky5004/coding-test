# 배열 뒤집기 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `배열 뒤집기.java`

```java
import java.util.*;

class Solution {
    public int[] solution(int[] num_list) {
        int length = num_list.length;
        int temp = 0;

        for(int i=0; i<length/2; i++) {
            temp = num_list[i];
            num_list[i] = num_list[length - (i+1)];
            num_list[length - (i+1)] = temp;
        }

        return num_list;
    }
}
```

## 새로 배운 점

- **양 끝 맞바꾸기** — 앞 `i` 번째 ↔ 뒤 `i` 번째 교환 · 가운데 도달 시 끝
- **반복 범위 `length / 2`** — 끝까지 반복 시 두 번 교환 → 원래 순서로 복귀 · 홀수 길이의 가운데 칸은 제자리
- **임시 변수 `temp`** — 교환 중 덮어써지는 값의 보관 자리
- **복사본 없는 제자리 뒤집기** — 추가 배열 없음 · 원본 배열 변경
- **불필요한 `import java.util.*`** — `java.util` 클래스 미사용

## 처리 과정

입력 `[1, 2, 3, 4, 5]` · `length / 2` = 2번 반복

| `i` | 교환 칸 | 배열 |
| --- | --- | --- |
| 시작 | — | `[1, 2, 3, 4, 5]` |
| 0 | 0 ↔ 4 | `[5, 2, 3, 4, 1]` |
| 1 | 1 ↔ 3 | `[5, 4, 3, 2, 1]` |
| 끝 | 가운데 2 는 제자리 | `[5, 4, 3, 2, 1]` |

## 내 풀이와 차이

| | 이 풀이 (맞바꾸기) | 내 풀이 (`clone` 뒤 덮어쓰기) |
| --- | --- | --- |
| 추가 메모리 | 변수 하나 | 배열 복사본 하나 |
| 반복 횟수 | 절반 | 전체 |
| 복사본의 필요 | 없음 — 바꾸기 전 값의 `temp` 보관 | 있음 — 앞칸 덮어쓰기 뒤 사라지는 원래 값 |
