# 문자열 계산하기 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `문자열 계산하기.java`

```java
import java.util.Arrays;

class Solution {
    public int solution(String myString) {
        return Arrays.stream(myString.replaceAll("- ", "-").replaceAll("[+] ", "").trim().split(" ")).mapToInt(Integer::parseInt).sum();
    }
}
```

## 새로 배운 점

- **빼기 = 음수 더하기** — `10 - 2 + 3` → `10 + (-2) + 3` · 연산자 분기 없는 숫자 합계
- **`replaceAll` 첫 인자 = 정규식** — `+` 는 특수 문자 · `[+]` 로 글자 `+` 지정
- **`Integer.parseInt` 의 음수 문자열 처리** — `"-2"` → `-2`
- **불필요한 `trim()`** — 앞뒤 공백 없는 입력 · 치환 뒤에도 생기지 않는 앞뒤 공백

## 처리 과정

입력 `"10 - 2 + 3"`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `replaceAll("- ", "-")` | `"10 -2 + 3"` |
| 2 | `replaceAll("[+] ", "")` | `"10 -2 3"` |
| 3 | `trim()` | `"10 -2 3"` |
| 4 | `split(" ")` | `["10", "-2", "3"]` |
| 5 | `Arrays.stream(...)` | `Stream<String>` |
| 6 | `mapToInt(Integer::parseInt)` | `10, -2, 3` |
| 7 | `sum()` | `11` |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 (`switch`) |
| --- | --- | --- |
| 길이 | 한 줄 | 반복문 + `case` 둘 |
| 강점 | 짧은 코드 | 눈으로 따라가는 흐름 · 쉬운 중간값 출력 |
| 한계 | `*` `/` 추가 시 사용 불가 — 모든 항을 더하는 구조 | `*` `/` 는 `case` 추가 · 연산자 우선순위는 별도 처리 |
