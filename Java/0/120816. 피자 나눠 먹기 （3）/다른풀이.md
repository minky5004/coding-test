# 피자 나눠 먹기 (3) — 다른 풀이

> 같은 올림의 다른 표현 두 가지 · 내 풀이는 같은 폴더의 `피자 나눠 먹기 （3）.java`

```java
class Solution {
    public int solution(int slice, int n) {
        return (int) Math.ceil((double) n / slice);
    }
}
```

```java
class Solution {
    public int solution(int slice, int n) {
        return n / slice + (n % slice == 0 ? 0 : 1);
    }
}
```

## 새로 배운 점

- **`Math.ceil` 앞 `(double)` 필수** — `Math.ceil(n / slice)` 는 정수 나눗셈 `10 / 7 = 1` 먼저 · 올릴 소수점 자체가 사라진 `1.0` → 오답 `1`
- **`Math.ceil` 반환형 = `double`** — `int` 반환 위치의 `(int)` 변환
- **나머지 기준 올림** — 나누어떨어지지 않는 경우의 한 판 추가 · 조건 자체가 코드에 드러나는 형태

## 처리 과정

입력 `slice = 7` · `n = 10`

| 단계 | `Math.ceil` 풀이 | 나머지 풀이 | 내 풀이 |
| --- | --- | --- | --- |
| 1 | `(double) 10 / 7` → `1.428…` | `10 / 7` → `1` | `10 + 7 - 1` → `16` |
| 2 | `Math.ceil(1.428…)` → `2.0` | `10 % 7` → `3` · 0 아님 → `+1` | `16 / 7` → `2` |
| 3 | `(int) 2.0` → `2` | `1 + 1` → `2` | — |

입력 `slice = 4` · `n = 12` → 세 풀이 모두 `3`

## 내 풀이와 차이

| | `Math.ceil` | 나머지 | 내 풀이 `(n + slice - 1) / slice` |
| --- | --- | --- | --- |
| 강점 | `ceil` = 올림 · 메서드 이름 그대로의 의도 | 한 판 추가 조건이 보이는 흐름 | 정수 연산만 · 형 변환 없음 |
| 한계 | `(double)` 누락 시 오답 · 형 변환 두 번 | 나눗셈 · 나머지 두 번 계산 | 처음 보는 사람에게 `- 1` 의 이유가 안 보이는 관용구 |
