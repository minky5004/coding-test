# 개미 군단 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `개미 군단.java`

```java
class Solution {
    public int solution(int hp) {
        return hp / 5 + (hp % 5 / 3) + hp % 5 % 3;
    }
}
```

## 새로 배운 점

- **몫 = 그 개미 수 · 나머지 = 다음 개미 몫** — 큰 개미부터 `/` 로 개수 · `%` 로 남은 체력 전달
- **반복문 불필요** — `hp % 5` 결과 0~4 · 5 이상 남지 않는 나머지 · 단계마다 나눗셈 한 번
- **마지막 일개미 = 나머지 그대로** — 공격력 1 · `hp % 5 % 3` 이 곧 일개미 수
- **`/` `%` 우선순위 동일 · 왼쪽부터 계산** — `hp % 5 / 3` = `(hp % 5) / 3`

## 처리 과정

입력 `hp = 999`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `hp / 5` | `199` (장군개미) |
| 2 | `hp % 5` | `4` (남은 체력) |
| 3 | `hp % 5 / 3` | `1` (병정개미) |
| 4 | `hp % 5 % 3` | `1` (일개미) |
| 5 | `199 + 1 + 1` | `201` |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 (`while` 둘) |
| --- | --- | --- |
| 길이 | 한 줄 | `while` 둘 + 마지막 덧셈 |
| 동작 | 단계마다 나눗셈 한 번 | 같은 동작 · `while` 마다 본문 1회 실행 — `hp %= 5` 뒤 `hp >= 5` 불가 |
| 강점 | 짧은 코드 | 눈으로 따라가는 단계 · 쉬운 중간값 출력 |
| 한계 | 개미 종류 추가 시 식 전체 수정 | 개미 종류 추가 시 같은 블록 복사 |
