# 배열 회전시키기 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `배열 회전시키기.java`

```java
class Solution {
    public int[] solution(int[] numbers, String direction) {

        int length = numbers.length;
        int[] answer = new int[length];

        int direct = "right".equals(direction) ? 1 : -1;

        for (int i = 0; i < length; i++)
            answer[i] = numbers[(i - direct + length) % length];

        return answer;
    }
}
```

## 새로 배운 점

- **`% length` = 원형 인덱스** — 끝을 넘은 인덱스의 처음 복귀 · 끝 칸 분기와 `temp` 불필요
- **`+ length` 의 역할** — `i - direct` 가 `-1` 이 되는 자리(right · `i = 0`)의 음수 방지 · Java `%` 는 음수 입력에 음수 결과
- **방향 = 부호 하나** — left/right 분기 대신 `1` / `-1` · 반복문 하나로 두 방향 처리
- **새 배열에 담기** — 원본을 읽기만 하는 구조 · 옮기기 전 값이 덮이는 문제 자체가 없는 방식
- **`"right".equals(direction)`** — 리터럴을 앞에 두는 비교 · `direction` 이 `null` 이어도 예외 없음

## 처리 과정

입력 `numbers = [1, 2, 3]` · `direction = "right"` → `direct = 1` · `length = 3`

| `i` | `(i - 1 + 3) % 3` | `answer[i]` |
| --- | --- | --- |
| 0 | `2 % 3` = 2 | `numbers[2]` = 3 |
| 1 | `3 % 3` = 0 | `numbers[0]` = 1 |
| 2 | `4 % 3` = 1 | `numbers[1]` = 2 |

결과 `[3, 1, 2]` · left 면 `direct = -1` → 인덱스 `(i + 1) % 3` = `1, 2, 0` → `[2, 3, 1]`

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 (제자리 이동) |
| --- | --- | --- |
| 분기 | 삼항 연산자 하나 | `if` / `else if` 두 갈래 · 반복문 둘 |
| 메모리 | 새 배열 하나 | 추가 배열 없음 · `temp` 하나 |
| 원본 배열 | 그대로 | 변경 |
| 한계 | `%` 계산을 머릿속으로 따라가야 하는 인덱스 | 방향마다 다른 반복 순서(right 는 뒤에서부터) — 순서 실수 시 값 덮어쓰기 |
| k칸 회전 확장 | `direct` → `k` 교체 하나 | 반복문 k번 또는 새 로직 |
