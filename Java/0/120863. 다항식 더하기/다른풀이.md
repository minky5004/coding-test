# 다항식 더하기 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `다항식 더하기.java`

```java
class Solution {
    public String solution(String polynomial) {
        int xCount = 0;
        int num = 0;

        for (String s : polynomial.split(" ")) {
            if (s.contains("x")) {
                xCount += s.equals("x") ? 1 : Integer.parseInt(s.replaceAll("x", ""));
            } else if (!s.equals("+")) {
                num += Integer.parseInt(s);
            }
        }
        return (xCount != 0 ? xCount > 1 ? xCount + "x" : "x" : "") + (num != 0 ? (xCount != 0 ? " + " : "") + num : xCount == 0 ? "0" : "");
    }
}
```

## 새로 배운 점

- **답 = x항 조각 + 상수항 조각** — 두 조각을 따로 만든 뒤 이어 붙이기 · 경우마다 완성 문자열을 따로 쓰는 6갈래 분기 대신
- **` + ` 연결자의 조건 = 앞 조각의 존재** — `xCount != 0` 일 때만 붙는 `" + "` · 상수항만 있는 입력에서 맨 앞 `" + "` 가 붙지 않는 구조
- **중첩 삼항 연산자의 결합 순서** — `a ? b ? c : d : e` = `a ? (b ? c : d) : e` · 짧은 대신 괄호 없이는 읽기 힘든 한 줄
- **실행되지 않는 `"0"` 분기** — 제한사항의 모든 수 > 0 · 합이 0 인 다항식이 나오지 않는 입력 범위 · 내 풀이의 `return "0"` 도 같은 처지

## 처리 과정

입력 `"3x + 7 + x"`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `split(" ")` | `["3x", "+", "7", "+", "x"]` |
| 2 | `"3x"` → `replaceAll("x", "")` → `parseInt` | `xCount = 3` |
| 3 | `"+"` | 건너뛰기 |
| 4 | `"7"` → `parseInt` | `num = 7` |
| 5 | `"+"` | 건너뛰기 |
| 6 | `"x"` → `equals("x")` | `xCount = 4` |
| 7 | x항 조각 — `xCount > 1` | `"4x"` |
| 8 | 상수항 조각 — `num != 0` · `xCount != 0` | `" + 7"` |
| 9 | 두 조각 연결 | `"4x + 7"` |

실행 확인 — `"x"` → `"x"` · `"7"` → `"7"` · `"12x + 3"` → `"12x + 3"` · `"x + 99x"` → `"100x"`

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 |
| --- | --- | --- |
| 파싱 | `split(" ")` · `"+"` 건너뛰기 · `x` 제거 | 같은 방식 (`replace` · 인덱스 `for`) |
| 답 만들기 | 두 조각 연결 · 삼항 연산자 한 줄 | `count` 0 · 1 · 그 외 × `num` 0 여부 6갈래 `if` |
| 강점 | 짧은 코드 · 조각 단위 생각 | 경우마다 눈에 보이는 반환값 |
| 한계 | 괄호 없는 중첩 삼항 — 읽기 어려움 | 같은 `" + "` 연결이 여러 갈래에 반복 |
