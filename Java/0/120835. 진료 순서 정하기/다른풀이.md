# 진료 순서 정하기 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `진료 순서 정하기.java`

```java
class Solution {
    public int[] solution(int[] emergency) {
        int[] answer = new int[emergency.length];

        for(int i = 0; i < answer.length; i++){
            if(answer[i] != 0){
                continue;
            }
            int idx = 1;
            for(int j = 0; j < answer.length; j++){
                if(emergency[i] < emergency[j]){
                    idx++;
                }
            }
            answer[i] = idx;
        }
        return answer;
    }
}
```

## 새로 배운 점

- **순위 = 1 + 나보다 큰 원소 수** — 정렬 없는 이중 반복문 · 원소 10개 이하 → 비교 최대 100번
- **지역 변수 `idx` 로 세기** — 바깥 반복마다 1 로 초기화되는 카운터 · `Arrays.fill` 없는 코드
- **한 번도 참이 아닌 `if(answer[i] != 0) continue;`** — `answer[i]` 대입 시점 = `i` 번째 반복의 끝 · 검사 시점 `answer[i]` = 언제나 0

## 처리 과정

입력 `[3, 76, 24]`

| i | `emergency[i]` | 나보다 큰 값 | `idx` | `answer` |
| --- | --- | --- | --- | --- |
| 0 | 3 | 76 · 24 | 3 | `[3, 0, 0]` |
| 1 | 76 | 없음 | 1 | `[3, 1, 0]` |
| 2 | 24 | 76 | 2 | `[3, 1, 2]` |

실행 결과 — `[3, 76, 24]` → `[3, 1, 2]` · `[1, 2, 3, 4, 5, 6, 7]` → `[7, 6, 5, 4, 3, 2, 1]` · `[30, 10, 23, 6, 100]` → `[2, 4, 3, 5, 1]` · `[42]` → `[1]`

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 |
| --- | --- | --- |
| 순위 계산 | 같은 방식 — 나보다 큰 원소 수 + 1 | 같은 방식 |
| 세는 곳 | 지역 변수 `idx` → 끝에 한 번 대입 | `Arrays.fill(answer, 1)` 뒤 `answer[i]` 직접 증가 |
| 필요한 import | 없음 | `java.util.Arrays` |
| 군더더기 | 효과 없는 `continue` 검사 | 없음 |
