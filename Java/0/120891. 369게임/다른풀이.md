# 369게임 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `369게임.java`

```java
class Solution {
    public int solution(int order) {
        int answer = 0;

        while (order >= 1) {
            if (order % 10 == 3 || order % 10 == 6 || order % 10 == 9) answer ++;
            order /= 10;
        }

        return answer;
    }
}
```

같은 문제 댓글의 한 줄 풀이

```java
return String.valueOf(order).replaceAll("[^369]","").length();
```

## 새로 배운 점

- **`n % 10` = 끝자리 · `n /= 10` = 끝자리 제거** — 문자열 변환 없는 자릿수 순회 · 자릿수 합 · 숫자 뒤집기 문제의 공통 뼈대
- **중간 자리 `0` 의 무해함** — `3033` → `303` → `30` → `3` → `0` · `0` 인 자리에서도 이어지는 반복 — 자릿값이 아닌 몫 기준 조건
- **`[^369]` = 3 · 6 · 9 를 뺀 모든 글자** — 남긴 글자 수 = 박수 횟수 · 문자열 정렬하기 (1) 의 `[^0-9]` 와 같은 발상

## 처리 과정

입력 `29423`

| 반복 | `order % 10` | 박수 | `order /= 10` 뒤 |
| --- | --- | --- | --- |
| 1 | `3` | 1 | `2942` |
| 2 | `2` | 1 | `294` |
| 3 | `4` | 1 | `29` |
| 4 | `9` | 2 | `2` |
| 5 | `2` | 2 | `0` → 종료 |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 |
| --- | --- | --- |
| 자릿수 꺼내기 | `% 10` · `/ 10` 산술 | `Integer.toString` → `split("")` |
| 반복 | `while` 하나 | `for` 두 겹 · 늘 1회 도는 안쪽 — 한 글자 문자열의 `split("")` |
| 비교 | `int` 의 `==` | `String` 의 `equals` |
| 중간 객체 | 없음 | `String[]` 두 종류 |
