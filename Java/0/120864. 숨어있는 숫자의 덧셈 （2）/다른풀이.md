# 숨어있는 숫자의 덧셈 (2) — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `숨어있는 숫자의 덧셈 （2）.java`

```java
class Solution {
    public int solution(String my_string) {
        int sum = 0;
        int num = 0;
        char[] chars = my_string.toCharArray();
        for (int i = 0; i < chars.length; i++) {
            if (Character.isDigit(chars[i])) {
                num = num * 10 + (chars[i] - '0');
            } else {
                sum += num;
                num = 0;
            }
        }
        sum += num;
        return sum;
    }
}
```

## 새로 배운 점

- **`num * 10 + 새 자릿수`** — 문자 하나씩 읽으며 여러 자리 수 조립 · `'1'` `'2'` → 1 → 12
- **`chars[i] - '0'`** — 문자 → 숫자 변환 · `'0'`~`'9'` 의 연속된 문자 코드 활용 · `Integer.parseInt` 불필요
- **`Character.isDigit`** — 정규식 없는 숫자 판별
- **반복문 뒤 `sum += num;`** — 문자열 끝이 숫자인 경우의 마지막 수 · 누락 시 `"1a2b3c4d123"` 의 123 이 빠진 합계

## 처리 과정

입력 `"aB12c3"`

| 문자 | 숫자? | `num` | `sum` |
| --- | --- | --- | --- |
| `a` | X | 0 | 0 |
| `B` | X | 0 | 0 |
| `1` | O | 1 | 0 |
| `2` | O | 12 | 0 |
| `c` | X | 0 | 12 |
| `3` | O | 3 | 12 |
| 반복문 뒤 | — | 3 | 15 |

실행 결과 — `"aAa1B2cC34oOp"` → `37` · `"1a2b3c4d123"` → `133` · `"abc"` → `0` · `"999999"` → `999999`
