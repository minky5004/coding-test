# 문자열 정렬하기 (1) — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `문자열 정렬하기 (1).java`

```java
import java.util.*;

class Solution {
    public int[] solution(String my_string) {

        my_string = my_string.replaceAll("[a-z]","");

        int[] answer = new int[my_string.length()];

        for(int i =0; i<my_string.length(); i++){
            answer[i] = my_string.charAt(i) - '0';
        }

        Arrays.sort(answer);

        return answer;
    }
}
```

## 새로 배운 점

- **`char - '0'` = 그 숫자의 `int` 값** — `'0'`~`'9'` 의 연속 문자 코드(48~57) · `'7' - '0'` → `7` · `split` · `parseInt` 없는 변환
- **`charAt(i)` 로 한 글자 직접 접근** — `split("")` 이 만드는 `String[]` 생략
- **`Arrays.sort` 의 제자리 정렬** — 반환값 없음 · 스트림 → 배열 왕복 생략
- **남길 것을 적는 정규식 `[^0-9]`** — 다른 풀이에서 본 변형 · 지울 글자를 나열하는 `[a-z]` 보다 대문자 · 기호 입력에 안전한 쪽

## 처리 과정

입력 `"hi12392"`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `replaceAll("[a-z]", "")` | `"12392"` |
| 2 | `new int[5]` | `[0, 0, 0, 0, 0]` |
| 3 | `charAt(i) - '0'` 반복 | `[1, 2, 3, 9, 2]` |
| 4 | `Arrays.sort(answer)` | `[1, 2, 2, 3, 9]` |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 |
| --- | --- | --- |
| 글자 → 숫자 | `charAt(i) - '0'` | `split("")` → `Integer.parseInt` |
| 정렬 | `Arrays.sort` (제자리) | `Arrays.stream(ans).sorted().toArray()` (새 배열) |
| 중간 객체 | `int[]` 하나 | `String[]` + `int[]` + 스트림 |
| 공통 뼈대 | 문자 제거 정규식 → 같은 길이 `int[]` → 정렬 | 〃 |
