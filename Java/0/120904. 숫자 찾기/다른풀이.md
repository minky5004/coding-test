# 숫자 찾기 — 다른 풀이

> 정답 제출 뒤 내 풀이를 `indexOf` 로 줄인 코드 · 내 풀이는 같은 폴더의 `숫자 찾기.java`

```java
class Solution {
    public int solution(int num, int k) {
        int idx = String.valueOf(num).indexOf((char) ('0' + k));
        return idx == -1 ? -1 : idx + 1;
    }
}
```

## 새로 배운 점

- **`indexOf` = 직접 짠 탐색 반복문** — 첫 등장 위치(0부터) · 미발견 시 `-1`
- **`(char) ('0' + k)`** — 숫자 0~9 → 문자 `'0'`~`'9'` · 반대 방향은 `c - '0'`
- **`int` + `char` 결과 = `int`** — `'0' + 1` 은 `49` · `(char)` 캐스팅으로 `'1'`
- **0부터 세는 인덱스 · 1부터 세는 문제** — `+1` 보정 · "없음" 표시 `-1` 은 보정 제외

## 처리 과정

입력 `num = 29183` · `k = 1`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `String.valueOf(num)` | `"29183"` |
| 2 | `(char) ('0' + k)` | `'1'` |
| 3 | `indexOf('1')` | `2` |
| 4 | `idx == -1 ? -1 : idx + 1` | `3` |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 (`split` + 반복문) |
| --- | --- | --- |
| 길이 | 두 줄 | 반복문 + `Objects.equals` |
| 만드는 객체 | 문자열 하나 | 한 글자 `String` 자릿수만큼 · 반복마다 `String.valueOf(k)` 하나씩 |
| 강점 | 표준 메서드 하나로 끝나는 탐색 | 위치 계산이 눈에 보이는 흐름 |
| 한계 | k 가 0~9 일 때만 성립하는 `'0' + k` | 자릿수만큼 쌓이는 객체 생성 |

## 또 다른 풀이 — 앞에 한 글자 붙이기

> 프로그래머스 `다른 사람의 풀이` 좋아요 1위 코드

```java
class Solution {
    public int solution(int num, int k) {
        return ("-" + num).indexOf(String.valueOf(k));
    }
}
```

- **`"-" + num`** — 문자열 + 숫자 = 문자열 · `String.valueOf` 없는 변환
- **앞에 붙인 한 글자** — 인덱스 0 자리 차지 · 숫자 위치가 1부터 세어지는 효과 · `+1` 보정 불필요
- **`-1` 그대로** — 미발견 시 `indexOf` 결과가 곧 문제의 답
- **한계** — `"-"` 의 의도가 코드에 드러나지 않는 구조 · 실무보다 코테용 요령
