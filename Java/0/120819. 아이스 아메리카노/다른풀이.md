# 아이스 아메리카노 — 다른 풀이

> 프로그래머스 `다른 사람의 풀이` 에서 고른 코드 · 내 풀이는 같은 폴더의 `아이스 아메리카노.java`

```java
class Solution {
    public int[] solution(int money) {
        return new int[] { money / 5500, money % 5500 };
    }
}
```

## 새로 배운 점

- **반복 빼기 = 나눗셈** — 5500 을 뺄 수 있는 횟수 = 몫 `/` · 뺄셈 뒤 남은 돈 = 나머지 `%`
- **`int / int` 의 정수 나눗셈** — 소수점 버림 · 그대로 잔 수
- **배열 리터럴 `new int[] { a, b }`** — 크기 지정과 칸별 대입 없이 한 줄 생성 · 반환문 안에서 바로 사용

## 처리 과정

입력 `15000`

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `money / 5500` | `2` |
| 2 | `money % 5500` | `4000` |
| 3 | `new int[] { 2, 4000 }` | `[2, 4000]` |

## 내 풀이와 차이

| | 이 풀이 | 내 풀이 (`while` 빼기) |
| --- | --- | --- |
| 반복 횟수 | 0 — 연산 두 번 | 잔 수만큼 — `money` 최대 1,000,000 → 181번 |
| 길이 | 한 줄 | 반복문 + 배열 칸별 대입 |
| 결과 | 같은 값 · `money` 0 에서 `[0, 0]` | 같은 값 |
